## ปัญหา คุณค่า และผู้ใช้
พิสูจน์ว่าการหาไข่ ฝึกตัวเดิม และยอมเสียตัวต้นทางเพื่อลุ้นลูกใหม่สนุกพอให้กลับมาทำซ้ำหรือไม่ ผู้ทดลองแรกคือลูกของผู้พัฒนาคนเดียว ใช้คอมพิวเตอร์1–4คน เป้าหมายเกมเต็มทุกวัย ไม่อนุมานว่าผลจากลูกคนเดียวใช้แทนตลาดทั้งหมดได้

## ข้อที่ผู้ใช้ยืนยัน
- C-01: เกม Roblox ฟักไข่ ผสมเพื่อได้ตัวใหม่ และต่อสู้
- C-02: ทำ Discovery/System Design ก่อน implementation
- C-03: ต้องมีคำสั่งเริ่ม implementation จากผู้ใช้ก่อนเขียนโค้ด
- C-04: เป้าหมายทุกวัย สนุกกับการพัฒนาตัวละครและลุ้นผสม
- C-05: ช่วงเริ่มเล่นได้ลองหาไข่ ฟัก สู้ ผสม และอยากกลับมาลุ้นผล
- C-06: ผสมสำเร็จเสียตัวต้นทาง มีเจตนาเพิ่มความหายากและลดจำนวนตัว
- C-07: ไม่มีระบบใช้ตัวซ้ำอัปเกรดโดยตรง
- C-08: ภาพเกมเต็มมี PvE/บอส/PvP และ turn-based auto/manual
- C-09: ทำคนเดียว ให้ลูกลองก่อนและพิสูจน์ความสนุกก่อนทำต่อ
- C-10: รุ่นทดลองพื้นที่เล็ก 6–8แบบ ฟัก/ผสม/PvE manual; เลื่อนบอส/PvP/auto
- C-11: Base Rarity + Jackpot และ Rarity ไม่เท่ากับ Power เสมอ
- C-12: Controlled Random สำหรับการผสม
- C-13: ตัวเดิมเติบโตจากการต่อสู้ได้; เลเวล/สกิล/รูปลักษณ์เป็นแนวคิดที่ยกมา
- C-14: ไข่จากสำรวจ ชนะ ซื้อด้วยรางวัล และไข่เริ่มต้นสุ่มได้ตัวธรรมดา
- C-15: ชนิดเดียวกันผสมได้
- C-16: Base ตามตารางคู่ rarity; Jackpot ข้ามสูงกว่า Base มากกว่าปกติ ไม่มี Secret Character ใน MVP
- C-17: Species + Element และ event มีผลต่อการสุ่ม
- C-18: สืบทอด Skill/Potential; cap5ดาว ดาวละ3%
- C-19: MVP ต่อสู้1ต่อ1
- C-20: ผสม2ตัวหายไป ได้1ตัวใหม่
- C-21: Creature มี Potential Type และเริ่มดาวใหม่เมื่อได้ rarity ใหม่
- C-22: ดาวสืบทอดใช้ค่าเฉลี่ย มีโอกาสเพิ่มต่ำมากไม่เกินดาวสูงสุดของตัวต้นทาง และ Level มีผล
- C-23: 3ช่อง: Speciesไม่สืบทอด, Inherited1สกิล, Growthปลดล็อกตามการเติบโต
- C-24: สืบทอดเฉพาะสกิลตัวต้นทางที่ผ่าน Compatibility; Speciesห้าม, Elementต้องรองรับ, Universalข้ามได้; มีทั้งสองตัวเพิ่มโอกาส
- C-25: ไม่มี Skill Mutation ใน MVP; ตัว rarity ต่ำมีคุณค่าจากสกิลและ SpeciesเดียวมีBuildต่างได้
- C-26: World Condition Day/Night/Rain ปรับ Weight Species/Element เท่านั้น ไม่ปรับ Jackpot/Potential/Skill
- C-27: เพิ่ม Speed เป็นค่าสถิติต่อสู้
- C-28: ทดสอบคอมพิวเตอร์เป็นหลัก
- C-29: ผู้เล่นพร้อมกัน1–4คน
- C-30: หลุดยกเลิกแมตช์และเริ่มใหม่ได้ ไม่เสียของ รางวัลที่บันทึกแล้วคงอยู่

## MVP ปัจจุบัน
พื้นที่สำรวจเล็ก, ไข่ส่วนตัว3จุด, catalog8ตัว/2Species/2Element/4rarity, คอลเลกชันและล็อกตัวโปรด, ฟัก, ซื้อไข่ด้วยCoin, Controlled Mix2→1พร้อมpreview, Skill/Potential inheritance, Level/Growth, สนามฝึกPvE1ต่อ1, Speed/cooldown, World Condition, durable profile/recovery. ตัวเลขรายละเอียด D-01–D-25

นอกMVP: บอส/PvP/auto, Secret, Skill Mutation, trade,เงินจริง/Robux,ขายของ,เร่งฟัก,มือถือเป็นrelease target, multi-elementในตัวเดียว, crit/miss/stun/heal/DoT/extra-turn. บอส/PvP/autoยังอยู่ในวิสัยทัศน์เกมเต็ม; trade/monetizationของเกมเต็มไม่เคยยืนยันว่าจะทำ

ยังไม่ตัดสินใจ: การเปลี่ยนรูปลักษณ์เมื่อLevelโตและevoแยกจากการผสม (O-01) ไม่ตีความว่ามีระบบแยกแล้วหรือถูกผู้ใช้ตัดออกแล้ว

## Core journey และผลผิดปกติ
รับstarterครั้งเดียว → ฟัก → สำรวจไข่ → ฝึกสู้ → ปลดล็อกGrowth → ดูpreview → ผสม → ดูลูก/สกิล → ทดลองลูกแล้วทำรอบใหม่. ไม่มีลำดับบังคับ: ผู้เล่นผสมก่อนGrowthได้แต่ช่องInheritedอาจว่าง

เงินหมด/เหลือตัวเดียวมีไข่ฟรีและสนามฝึกเป็นทางไปต่อ; ของเต็มไม่หักของทิ้ง; saveยังไม่ทราบผลแสดงpending; โหลดerrorไม่เริ่มprofileใหม่; หลุดแมตช์ที่ไม่จบยกเลิกไม่เสียของ ส่วนprepared operationต้องrecover

## Acceptance criteria
เกณฑ์สำหรับbaselineที่เลือก ไม่ใช่ผลทดสอบที่ผ่านแล้ว AC-03ตรวจscope ไม่ใช่งานสร้างPvP/autoในMVP

- AC-01: ผสมสำเร็จใช้ Creature ที่เป็นเจ้าของสอง instance และได้ลูกหนึ่งตัวพร้อมหัก20Coinในรายการเดียว (D-16/D-23)
- AC-02: ชนิดเดียวกันผสมได้ แต่ไม่มีเส้นทางใช้ตัวซ้ำอัปเกรดโดยตรง
- AC-03: รุ่นทดลอง1ต่อ1 PvE/manual; บอส/PvP/auto เป็นภาพเกมเต็มนอกMVP
- AC-04: retryรายการเดิมไม่หักของหรือสุ่มผลใหม่ตาม D-23/D-24
- AC-05: โปรไฟล์ใหม่ได้ไข่1และCoin20ครั้งเดียว ฟักได้Common C01/C02เท่านั้น
- AC-06: ผลผสมอยู่ในcatalogและrarityที่D-08/D-20อนุญาต
- AC-07: Base/JackpotตรงD-08 ไม่ใช้rarityเป็นตัวคูณพลัง
- AC-08: ตัวเดิมได้Level/Growth/PotentialตามD-05/D-17 ไม่ใช้ตัวซ้ำอัปเกรด
- AC-09: Baseทั้ง10คู่ตรงD-08 ไม่มีSecret Character
- AC-10: ทุกWorld phaseใช้WeightD-20และให้rarity marginalเท่าเดิม
- AC-11: Potentialจำนวนเต็ม0–5 โบนัสเฉพาะTypeดาวละ3%แบบเส้นตรง
- AC-12: แต่ละฝั่งมีหนึ่งCreatureและหนึ่งคำสั่งต่อรอบถ้าแมตช์ไม่จบ
- AC-13: ผสม2→1จำนวนCreatureลดสุทธิ1
- AC-14: Inheritedมาจากสกิลปลดล็อกของตัวต้นทางผ่านCompatibility ชุดว่างให้ช่องว่าง
- AC-15: สกิลมีในทั้งสองตัวน้ำหนัก2 เทียบกับ1เมื่อมีตัวเดียว
- AC-16: Worldไม่แก้สูตรJackpot/Potential/Skill เมื่อยึดลูกและตัวต้นทางคงที่
- AC-17: ค่าเฉลี่ยปัดลง/เพิ่ม1ตามLevelไม่เกินเพดานพ่อแม่; rarityไม่ตรงทั้งสองรีเซ็ต0 (D-02/D-03)
- AC-18: Potential 5 ดาวเพิ่มเฉพาะ stat ตาม Type 15% จากฐาน Species/Level โดยไม่คูณ rarity หรือ World Condition
- AC-19: ดาว 2/4 ที่ Level 10/10 และไม่รีเซ็ตได้ 3 หรือ 4 ดาวเท่านั้น โดยน้ำหนักได้ 4 คือ 1.9%; 3/3 ไม่มีทางผสมได้ 4
- AC-20: rarity ที่ไม่มีในคู่เดิมให้ 0 ดาว; ถ้าตรงตัวต้นทางอย่างน้อยหนึ่งตัวใช้สูตรสืบทอด
- AC-21: ทุก 5 ชัยชนะเฉพาะตัวเพิ่มดาว 1 จน cap 5; ตัวใหม่เริ่มตัวนับ 0
- AC-22: ลูกเริ่ม Level 1/XP 0 และ Growth Skill ล็อกจน Level 5; Inherited Skill ที่ได้ใช้ได้ทันที
- AC-23: ชุดสกิลว่างยังผสมได้โดยช่องว่าง; มีสกิลเหมือนกันทั้งสองตัวนับน้ำหนัก 2 ไม่ซ้ำตามจำนวนช่อง; Growth Skill ที่ล็อกไม่เข้าชุดสุ่ม
- AC-24: ตรวจตาราง Base ครบ 10 คู่และสลับตำแหน่งได้ผลเดียวกัน; แสดงโอกาส/การเสียตัว/เงื่อนไขรีเซ็ตดาวก่อนผสม
- AC-25: ผล rarity อยู่ในตาราง D-08 และผลรวมโอกาสแต่ละแถว 100%; World Condition ไม่แก้โอกาส rarity
- AC-26: cooldown ตาม D-09 ใช้เทิร์น 1 แล้วพร้อมเทิร์น 4; โจมตีพื้นฐานใช้ได้เสมอ; HP 0 จบแมตช์ทันที
- AC-27: แพ้ไม่ลดตัว/Level/ดาว/เงินและไม่เพิ่มรางวัล; แมตช์ใหม่เริ่ม HP เต็ม
- AC-28: Speed 12/8 ให้ฝั่ง 12 เริ่ม, 8/12 ให้ฝั่ง 12 เริ่ม โดยไม่ขึ้นกับว่าเป็นผู้เล่นหรือมอนสเตอร์
- AC-29: Speed เสมอให้ผู้เริ่มรอบแรกโอกาสเท่ากัน และสลับผู้เริ่มในรอบเสมอถัดไป; ถ้าแมตช์ไม่จบ แต่ละรอบแต่ละฝั่งได้หนึ่งคำสั่งเท่านั้น
- AC-30: cooldown ยังอิงเทิร์นส่วนตัว ใช้ครั้งที่ 1 พร้อมครั้งที่ 4 ไม่ขึ้นกับตำแหน่งในรอบ; HP 0 จบก่อนคำสั่งที่เหลือ
- AC-31: catalog มี 8 unique IDs แต่ละ rarity มี 2 definitions ครบ Fire/Water และแต่ละ Species มี 4 rarity
- AC-32: สกิลทุกตัวอ้างอิง ID ที่มีจริง; Growth ตรง Compatibility; Species Skill สืบทอดไม่ได้; BASIC ไม่กิน Skill Slot
- AC-33: C01 Level 5/0 ดาวได้ 126/36/26/20; Level 1/5 ดาว ATK 32; ใช้ D-14 ปัดครั้งเดียวหลัง Potential
- AC-34: ตัวอย่าง C01/C08 ใน D-15 จบเมื่อรอบ 4 โดย C08 เหลือ HP 18; ยืนยันคณิตศาสตร์และ cooldown ไม่ใช่เป้าหมายผลทุกการเล่น
- AC-35: สกิล ID ซ้ำช่องใช้ cooldown เดียวกัน; Shield ไม่ซ้อนและหมดตาม D-13; damage ไม่ทำ HP ติดลบ
- AC-36: ตัวอย่างผสม C01/C03 ตาม D-15 ให้ชุดสกิลต่างกันตาม Element ของลูก และ rarity ใหม่รีเซ็ตดาว
- AC-37: ผู้เล่นใหม่ได้ไข่1/Coin20 เพียงครั้งเดียว แม้เข้าใหม่; ทุกไข่ฟักได้ C01/C02 เท่านั้นที่ 50/50
- AC-38: ชนะ4ครั้งจาก Level1 ได้ Level5/totalXP80 และ Growth ใช้ได้; ครั้ง5ได้ดาวแรก; ครั้ง24 Level10/totalXP480; XP ไม่เกิน480 แต่รางวัลอื่นยังได้
- AC-39: ผสมที่ Coin19 ปฏิเสธและไม่เปลี่ยนข้อมูล; Coin20 ผสมสำเร็จหัก20และ 2→1; ตัวล็อก/อยู่ในแมตช์ผสมไม่ได้
- AC-40: ไม่มีเงินยังเก็บไข่ฟรีและลงสนามฝึกได้; เก็บจุดเดิมก่อน90วินาทีไม่ได้ รวมเข้าใหม่; offline ไม่สะสมหลายใบต่อจุด
- AC-41: Creature เต็มฟักไม่ใช้ไข่ แต่ผสมลดจำนวนได้; eggเต็มซื้อ/เก็บไม่หักเงินหรือ cooldown; ไข่รางวัลค้างรับไม่หาย
- AC-42: ชัยชนะแรกได้ไข่1แน่นอนและไม่มีสุ่มเพิ่ม; ครั้งถัดไป20%; รางวัลแมตช์หนึ่งให้ซ้ำไม่ได้
- AC-43: สูตรดาวรักษา startingPotentialStars และเพิ่มทุก5ชัยชนะใหม่; cap10 ทำโอกาสสืบทอดดาวได้สูงสุด1.9%
- AC-44: boundary phase ตรง D-19 ทุกเซิร์ฟเวอร์อ้างอิงวงจรเดียว ไม่รีเซ็ตเมื่อเข้าใหม่
- AC-45: ทั้ง36คู่ต้นทาง×4phase มีผลรวมโอกาส100% และ rarity marginal ตรง D-08 ทุกกรณี สลับต้นทางได้ผลเดิม
- AC-46: C01/C03 Day/Clear ให้ C01 ภายใน Common9/11; Night/Rain ให้ C01/C02 รวมอย่างละ45%, C03 7.2%, C04 1.8%, C05/C06 อย่างละ0.5%
- AC-47: preview หมด phase ไม่หักเงินหรือ Creature; เมื่อยอมรับรายการแล้ว phase เปลี่ยนไม่สุ่มใหม่; config weights ผิดปฏิเสธโดยไม่หักทรัพยากร
- AC-48: เมื่อตรึงลูกและตัวต้นทาง การเปลี่ยน world ไม่แก้สูตร Potential หรือ weights Skill; ไข่พื้นฐานยัง50/50และ rarity/Jackpot ไม่รับ weather modifier
- AC-49: preparedผลสุ่มถูกกู้คืนเดิม; committedคืนreceiptโดยไม่หักซ้ำ; stale/unknown IDไม่เริ่ม mutation
- AC-50: sessionเก่าหมดสิทธิ์เขียนไม่ได้หลังsessionใหม่ได้generationใหม่
- AC-51: โหลดerror/unknown schemaไม่เขียนdefaultทับ; grantครั้งแรกไม่เกิดซ้ำ
- AC-52: userเห็นsuccessหลังcommitเท่านั้น; timeoutคงpendingจนทราบผล ไม่คืนของเดา
- AC-53: แมตช์ไม่จบยกเลิกโดยไม่เสียของ; rewardที่preparedแล้วคืนได้ครั้งเดียว
